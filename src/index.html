OSS, the Operating System Simulator

A scheduler simulator written by six students for Operating Systems I at the University of Piraeus in January 1998, rebuilt in JavaScript from its Windows executable. What this is, and where it came from

Log in with any name and pick a scheduler. Then try scr hello, prn a long job and cmp /abc /abd one after the other, and watch the Current Task field: FIFO runs them in order, round robin takes turns, shortest job first lets the short ones through. dirtasks lists the task table and edit example.bch opens the batch file the program shipped with. Help has the team's own manual. The batch files you save stay in this browser.
